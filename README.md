# Harvest International School Website

Independent migration/reconstruction of the Harvest International School website from the supplied legacy site source.

## Migration status

This repository currently contains the reconstruction foundation. The objective is to preserve the existing Harvest website design and content while removing dependence on the legacy site builder runtime.

### Included
- Home
- About
- Gallery
- Jobs
- Contact
- Enrol Your Child
- Shared responsive styling
- Recovered school media assets
- Legacy-source inventory for migration verification

### Important
The website is still under reconstruction and should not replace the current production website until visual, content, forms, responsive behaviour, and domain verification are complete.

Forms that depended on the old site builder backend are intentionally not treated as production-ready yet.
